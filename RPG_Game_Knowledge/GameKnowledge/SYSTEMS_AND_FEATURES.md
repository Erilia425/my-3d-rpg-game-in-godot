## Feature planning template
For each proposed feature, record:
1. Player-facing behavior
2. Required scenes/scripts/resources
3. Existing systems it must connect to
4. Data that must persist
5. UI and input requirements
6. Edge cases
7. Test plan
8. Status: idea / planned / in progress / implemented / tested
